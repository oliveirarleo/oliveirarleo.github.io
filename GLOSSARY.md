# Wishlist glossary

- **User**: A person identified by a unique, case-insensitive display name and able to manage their own wishes. This is not an account with a username and password.
- **User secret**: A six-character, case-insensitive bearer secret used to assume a User on a browser. Losing it removes self-service access until an administrator resets it.
- **Wish**: A publicly visible gift idea with a name and normalized web link, owned by exactly one User.
- **Assume a User**: Authenticate with a User secret so the browser can add and remove that User’s wishes.
- **Active User**: The User currently assumed on this browser.
